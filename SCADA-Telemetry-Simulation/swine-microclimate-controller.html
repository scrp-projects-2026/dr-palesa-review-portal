01

The OR Gate Logic

The OR gate (U1A) evaluates two key environmental threats: excess internal thermal load (A) or toxic gas accumulation (B). If **either** condition returns a logic high signal (1), the output triggers the ventilation pipeline request.

Formula: YOR=A∨B
02

The Cold-Draft Interlock

The first AND gate (U2A) checks if ventilation is requested (A∨B) **AND** if ambient temperature is above the freezing draft threshold (CSAFE). This guarantees fans never blow freezing air onto pigs during cold nights.

Formula: YFAN=(A∨B)∧C
03

Skin-Wetting Safeguard

The second AND gate (U2B) controls the evaporative water drippers. Drippers only turn on when fans are actively running (YFAN) **AND** the heat threshold (A) is met. This stops wet pigs from suffering pneumonia under stagnant air.

Formula: YDRIP=YFAN∧A
